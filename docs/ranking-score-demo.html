📊 O que é Ranking Score?

O Ranking Score é uma métrica do Meilisearch (valor de 0.0 a 1.0) que indica o quão relevante um resultado é em relação à sua busca.

  • Alta relevância (≥80%): Badge verde - resultado muito relevante
  • Média relevância (50-79%): Badge amarelo - resultado moderadamente relevante
  • Baixa relevância (<50%): Badge vermelho - resultado pouco relevante

💻 Código Implementado

O plugin agora calcula automaticamente a relevância e exibe badges coloridos:

// Cálculo da relevância (class-search-shortcode.php)
$ranking_score = isset($hit['_rankingScore']) ? $hit['_rankingScore'] : 0;
$relevance_percent = round($ranking_score * 100, 1);
$relevance_class = $ranking_score >= 0.8 ? 'high' 
                 : ($ranking_score >= 0.5 ? 'medium' : 'low');

Onde aparece:

  • ✅ Shortcode [meilisearch_search]: Badge visual ao lado de cada título
  • ✅ WP-CLI: Coluna "relevance" com percentual
  • ✅ API de Busca: Campo "_rankingScore" em todos os resultados
