reindex()

class-cli.php : 67

Reindex all posts for a specific blog or all blogs in the network.

public reindex(array<string|int, mixed> $args, array<string|int, mixed> $assoc_args) : mixed

OPTIONS

[--blog_id=<blog_id>] : The blog ID to reindex. If not provided, reindexes all blogs in the network.

[--url=] : The blog URL to reindex (alternative to blog_id).

EXAMPLES

# Reindex a specific blog by ID
wp meilisearch reindex --blog_id=2

# Reindex a specific blog by URL
wp meilisearch reindex --url=http://example.com/labcom/

# Reindex all blogs in the network
wp meilisearch reindex

search()

class-cli.php : 295

Search posts across the network.

public search(array<string|int, mixed> $args, array<string|int, mixed> $assoc_args) : mixed

OPTIONS

: The search query.

[--limit=] : Maximum number of results. Default: 20

[--blog_id=<blog_id>] : Search only in specific blog. If not provided, searches all blogs.

[--format=] : Output format. Options: table, json, csv, yaml. Default: table

EXAMPLES

# Search for "mundo" across all blogs
wp meilisearch search "mundo"

# Search in specific blog with limit
wp meilisearch search "inteligente" --blog_id=2 --limit=10

# Get results as JSON
wp meilisearch search "mundo" --format=json
